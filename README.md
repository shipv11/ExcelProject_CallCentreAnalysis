# ExcelProject_CallCentreAnalysis
This dashboard shows how a call centre has performed over the last six months.  I prepared the dashboard through the following steps:
-	Designed dashboard layout.
-	Created named ranges  on the data sheet.
-	Turned the data into a table so that it auto extends.
-	Calculated summary metrics and monthly metrics on the calculation sheet.
-	Pulled important metrics from the calculation sheet onto the dash sheet for easier access.
-	Displayed the following summary metrics:
1.	Average calls per month
2.	Average speed of answer which means the average time the call was in queue.
3.	Resolution rate which means the percentage of calls that said their problem was resolved.
4.	Service level which means the percentage of calls which were under the targeted queue time.
5.	Abandon rate which means the percentage of total calls that were cut before an agent received them.
-	Applied conditional formatting.
-	Created a combination chart to show the satisfaction level achieved by various agents vs the target.
-	Created sparklines to show the monthly trend in agent satisfaction level.
-	Created a percentage dial to display summary metrics.
-	Created a gauge chart to show service level for different months.
-	Used data validation to add interactivity to the dashboard.
